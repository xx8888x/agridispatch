### Software 軟體系統
1. 系統規格、資料庫設計與 **`03_認證與API安全規格.md`** 已移至 `07_系統分析及文件/`；修改 API 前先讀認證規格。
2. **`tools/`**：`sync-frontend.js`（demo → web / android 同步）、`check-frontend.js`（語法與連結檢查）、`record-mock-fixtures.js`（後端 demo 模式執行時錄製 `demo/mock/demo-fixtures.js`）。
3. **`demo/`**：前端唯一原始碼（路演 demo 模式），分 `AgriDispatch/`（小農、移工、冷鏈、黑轉白等前台頁）、`TechBackend/`、`linebot/` 三個子資料夾；修改後以同步腳本產生 `web/` 與 Android `assets/www/`。
4. **`backend/`**：Spring Boot 3.2 + JPA + H2 單體後端（port 3000），同時提供 `/demo/*`、`/web/*` 靜態頁（例：`/demo/AgriDispatch/index.html`）。
5. **`Line Bot/`**：純 Java LINE Bot（port 5000）。
6. **`database/`**：Oracle schema、通用 seed SQL 與 SQL Developer 連線設定。
