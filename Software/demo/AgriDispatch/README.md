# 智農派工 AgriDispatch - Demo 網站操作與導覽指引

本目錄為「農業外展調度 ╳ 雙軌智慧農事派遣平台」的互動式 Prototype / Demo 系統。  
**免裝 Node.js 或複雜編譯環境，雙擊 HTML 檔案即可於任何現代瀏覽器中完整體驗！**

---

## 快速啟動方式

1. **方式 A（最簡單，直接開啟）**：
   * 雙擊開啟 [`Demo/index.html`](./index.html)（進入品牌官方入口，含四大身分快速直通入口）。
   * 雙擊開啟 [`TechBackend/admin.html`](../TechBackend/admin.html)（**💻 科技營運與調度管理後台**，含 25 位農工名冊、5大派工類別、現場小工頭與全台產曆）。
   * 雙擊開啟 [`Demo/login.html`](./login.html)（四大角色專屬身分選擇大廳）。
   * 雙擊開啟 [`TechBackend/admin-login.html`](../TechBackend/admin-login.html)（管理人員與合作社調度員專屬驗證登入門戶）。
   * 雙擊開啟 [`Demo/app.html`](./app.html)（傳統多角色戰情與調度平台）。
2. **方式 B（本機 HTTP 伺服器，若需於區域網路/手機展示）**：
   ```bash
   # 在本目錄執行 Python 內建輕量伺服器
   python -m http.server 8080
   # 於瀏覽器開啟 http://localhost:8080/Demo/
   ```

### 1. 👨‍🌾 小農與契作商叫工中心 (`view-farmer`)
* **即時智慧派工試算器**：
  * 可切換作物類別（愛文芒果、高樹洋蔥、設施甜椒、三星青蔥、文旦柚）。
  * 調整耕作面積（分地），系統自動換算需求工時與建議派遣人數。
  * **產季早鳥工時包模式**：即時試算 315 元/hr 不打折的工時包金額與 20% 保證出工定金（鎖定名額・優先排班）。
  * 點擊「立即送出派工預約」，訂單即時生成並無縫串接至調度戰情室。

### 2. 🛰️ 派工調度戰情中心 (`view-dispatch`)
* **全台產曆排程與工班接送監控**：即時掌握 4 個工班、20 位在籍外展移工分佈。

### 3. 👷 外展移工多語工單中心 (`view-worker`)
* **三語系切換**：繁體中文、🇻🇳 Tiếng Việt（越南語）、🇮🇩 Bahasa Indonesia（印尼語）。
* **手機視角體驗**：即時呈現今日出勤時間、接送專車（含司機電話）、田區座標、農務防中暑警語。
* **GPS 數位打卡簽到**：點擊「📍 GPS 抵達現場數位打卡」立即模擬現場簽到。
* **薪資透明度儀表**：透明顯示基本工資 ＋ **農業部就業獎勵津貼（最高 NT$ 8,800/月）** 之發放狀態。

### 4. 📝 合規人才庫自主登錄 (`view-talent`)
* 針對國內轉聘移工、本國機耕技師之自主登錄管道。
* 內建符合《個人資料保護法第 19 條》之告知暨授權同意條款，**拒絕違法爬蟲，打造高價值私域人才庫**。
