# Google Play 資料安全表單與商店資訊草稿（客戶端 App）

> 版本：2026-10-15 草稿
> 適用：客戶端 App `com.agridispatch.app`（農場主、本國工人；外籍移工入口目前下架）。後台 App `com.agridispatch.app.admin` 只上內部測試軌，見第肆章。
> 依據：2026-10-15 的程式現況（`Software/android`、`Software/demo`、`Software/backend`）。程式改了收集的資料，這份表單也要跟著改；Play 會比對 App 實際行為。
> 法規與政策解讀標「【待確認】」，請律師或熟悉 Play 政策的人確認後再送出。

## 壹、 送審前要先補的事（會擋上架）

| # | 事項 | 現況 | 要做什麼 |
|---|---|---|---|
| 1 | **隱私權政策網址** | 專案裡沒有隱私權政策 | Play 規定必填，且要公開、不需登入就能開。內容至少寫明：蒐集者（科技公司與合作社的角色）、蒐集目的、資料類別、利用期間與地區、對象、方式、當事人權利與行使方式（個資法第 8 條告知事項【待確認】）、聯絡方式。正式網域 `agridispatch.tw` 尚未上線，需先決定放哪裡 |
| 2 | **刪除帳號** | App 可以自行註冊（農場主 `farmer-register.html`），但沒有刪除帳號的入口或網頁 | Play 規定可建立帳號的 App 必須：(1) App 內有申請刪除帳號的入口；(2) 另有網頁版申請網址（不用裝 App 也能申請），填在 Play Console。建議做法：「我的帳號」加「申請刪除帳號」→ 合作社後台審核 → 刪除或去識別化。出勤、工資紀錄依勞基法須保存一段期間（第 23 條工資清冊、第 30 條出勤紀錄，各 5 年【待確認】），刪除時要保留並在說明中告知 |
| 3 | **位置權限要用還是拿掉** | Manifest 宣告了 `ACCESS_FINE_LOCATION`／`ACCESS_COARSE_LOCATION`，原生橋接也有 `requestGpsLocation`；但目前沒有任何網頁呼叫它，打卡只送「作業地點文字」，後端也不存座標 | 二選一：**A.** 做 GPS 打卡（打卡時取座標送後端、後端存座標與精確度）→ 表單宣告「確切位置」「大概位置」；**B.** 上架前從 Manifest 拿掉兩個位置權限 → 表單不宣告位置。宣告了權限卻沒在表單說明，審查容易被退件 |
| 4 | **上架的版本連不連正式後端** | release 的 `API_BASE` 目前是空字串，App 用內建示範資料，不會把資料送出裝置 | 資料安全表單要跟「實際上架的那一版」一致。本草稿以**連正式後端**的版本撰寫；若先以示範資料版上架，第貳章幾乎全部改為「不收集」（另需確認 FCM 未啟用） |
| 5 | **審查用帳號（App 存取權）** | 登入後才能使用 | Play Console「App 存取權」要提供審查人員可登入的帳號與步驟（農場主、本國工人各一組）。帳號另外建，不要用 `08_DEV測試帳號清單.md` 的開發帳號，也不要寫進這份文件 |
| 6 | **開發人員帳號與聯絡資訊** | 專案裡沒有對外客服信箱 | 商店頁必填聯絡 Email。另確認以哪個名義開 Play 開發人員帳號（科技公司或合作社）【待確認】；2023 年起新開的機構帳號需 D-U-N-S 號碼並驗證身分 |
| 7 | **封閉測試** | 未開始 | 2023-11 之後新開的個人開發人員帳號，正式上架前需 12 位以上測試者連續 14 天參與封閉測試；機構帳號不受此限【待確認：以實際帳號類型為準】 |

## 貳、 資料安全表單逐題答案

### 2.1 資料收集與安全性

| 題目 | 答案 | 說明 |
|---|---|---|
| App 是否收集或分享任何必填的使用者資料類型？ | 是 | |
| 所有使用者資料在傳輸過程中都經過加密嗎？ | 是 | release 建置強制 `https`（`API_BASE` 非 https 會建置失敗）；明文 HTTP 只限開發位址 |
| 是否提供方式讓使用者要求刪除資料？ | 是 | **前提：完成第壹章第 2 項**。未完成前不能勾「是」 |
| 是否遵守 Play 家庭政策？ | 否（不適用） | App 對象為成年工作者與農場主，不以兒童為對象 |
| 是否經過獨立安全審查？ | 否 | 選填 |

### 2.2 收集的資料類型

「收集」= 資料從裝置傳送到我們的伺服器。全部資料**都不是暫時性處理**（會存在後端資料庫）。

| Play 類別 | 資料類型 | 收集 | 必填／選填 | 用途（Play 選項） | 實際內容與來源 |
|---|---|---|---|---|---|
| 個人資訊 | 姓名 | 是 | 必填 | App 功能、帳戶管理 | 農場主、工人姓名；訂單帶隊對口姓名 |
| 個人資訊 | 電話號碼 | 是 | 必填 | App 功能、帳戶管理 | 農場主、農場聯絡電話；工人電話；手機也可當登入帳號 |
| 個人資訊 | 地址 | 是 | 必填（農場主） | App 功能 | 農場主地址、農場地址（工班到場用） |
| 個人資訊 | 使用者 ID | 是 | 必填 | App 功能、帳戶管理 | 平台帳號、工號；綁定 LINE 時的 LINE 使用者 ID |
| 個人資訊 | 其他資訊 | 是 | 必填（工人）／選填 | App 功能、帳戶管理、詐欺防範與安全性 | 身分證字號（本國工人可用來登入）、居留證號與護照號碼（外籍，現下架）、國籍、農場主統一編號 |
| 財務資訊 | 購買記錄 | 是 | 必填（農場主下單） | App 功能 | 派工訂單、定金與付款狀態、發票號碼 |
| 財務資訊 | 其他財務資訊 | 是 | 必填（工人） | App 功能 | 薪資試算與薪資單（底薪、加班、勞健保自付額、實發）；保險投保薪資 |
| 財務資訊 | 使用者付款資訊 | **否** | — | — | 信用卡等付款資料由綠界在其網站輸入，App 與後端不經手 |
| 位置 | 確切位置、大概位置 | **依第壹章第 3 項** | 必填（打卡時） | App 功能、詐欺防範（確認在作業地點打卡） | 方案 A 才宣告；方案 B 則兩項都填「否」 |
| 健康與健身 | 健康資訊 | 【待確認】 | 選填 | App 功能 | 請假假別含「普通傷病假」「生理假」，可能被視為健康相關資訊。保守做法是宣告；或在請假介面只讓使用者選假別、不填病況並在政策說明 |
| 應用程式活動 | 其他使用者產生的內容 | 是 | 選填 | App 功能 | 請假事由、訂單交辦備註、工班評價留言 |
| 應用程式活動 | 其他動作 | 是 | 必填（工人） | App 功能 | 上下班打卡時間、工時、出勤紀錄 |
| 裝置或其他 ID | 裝置或其他 ID | 是 | 選填（允許通知才有） | App 功能 | Firebase 推播權杖（FCM token），用於推播派工與天候通知；登出時刪除 |

以下類別**全部填「否」**：電子郵件地址、種族與族裔、政治或宗教信仰、性傾向、相片與影片、音訊檔案、檔案與文件、日曆活動、聯絡人、電子郵件與簡訊內容、App 互動記錄（無分析工具）、應用程式內搜尋記錄、已安裝的應用程式、網頁瀏覽記錄、當機記錄與診斷（未使用 Crashlytics 或 Analytics）、信用評分、健身資訊。

### 2.3 資料分享

建議**全部填「不分享」**，理由是以下傳遞都屬 Play 定義的例外【待確認：請律師確認合作社與科技公司的角色】：

| 對象 | 傳遞的資料 | 適用的例外 |
|---|---|---|
| 有限責任智農農業勞務生產合作社（法定雇主） | 工人資料、出勤、薪資、保險 | 科技公司代管系統、為合作社處理資料（服務供應商）。若合作社被認定為資料的獨立控制者，則需改填「分享」【待確認】 |
| 綠界科技（金流） | 訂單金額、付款人名稱 | 使用者主動付款（使用者啟動的傳遞）、服務供應商 |
| Google Firebase Cloud Messaging | 推播權杖、通知內容 | 服務供應商 |
| LINE（官方帳號通知） | LINE 使用者 ID、通知內容 | 使用者主動綁定、服務供應商 |
| 勞保局等政府機關（加退保申報） | 工人投保資料 | 法律義務 |
| 農場主與工人互相看到的資料（工班成員姓名、帶隊對口電話） | 姓名、電話 | 屬服務本身功能的使用者間顯示，一般不列為分享【待確認】 |

### 2.4 刪除與保留說明（填在表單「資料刪除」補充說明，並同步寫進隱私權政策）

> 您可以在 App「我的帳號 → 申請刪除帳號」或透過網頁（網址待定）申請刪除帳號。合作社確認身分後，將刪除或去識別化您的帳號與個人資料。依勞動基準法須保存的出勤紀錄與工資清冊，以及依稅法須保存的交易與發票紀錄，會在法定期間內保留後刪除【待確認：期間與條文】。

## 參、 商店資訊草稿（繁體中文 zh-TW）

> 字數上限：App 名稱 30 字元、簡短說明 80 字元、完整說明 4,000 字元。
> 依 Play 中繼資料政策，說明只寫 App 目前真的有的功能；尚未確定的數字（例如 8,800 元就業獎勵、出工保證率）與暫停中的功能（外籍移工、工班合法化）不寫。

| 欄位 | 草稿 |

| 簡短說明 | 農場找合法工班、工人看任務打卡領薪，合作社派工一個 App 搞定。 |
| 應用程式類別 | 商業 |

| 網站 | 【待填】（正式網域上線後填） |
| 聯絡電話 | 合作社專線 (03) 388-1234（選填；請確認是否對外公開） |

### 3.2 完整說明

```
智農派工是農場主與農務工作者的派工 App。合作社是工人的法定雇主，負責排班、加保與發薪；農場主線上預約工班，工人在手機上看任務、打卡、查薪資。

【給農場主】
・線上預約派工：登錄農場後，選作物、面積、開工日與上午／下午時段，立即試算費用。
・我的訂單：查看每張訂單的工班、帶隊對口與履約進度，可修改預約或取消。
・派工行事曆：在月曆上看工班哪幾天到場。
・社區共享班表：和鄰近農戶一起認領合作社開出的工班時段。
・勞務費支出明細：訂單與付款紀錄一目了然，可下載用工證明。
・天候與派工通知：綁定 LINE 後，訂單狀態、定金入帳、天候警戒會即時通知。

【給工作者】
・今日任務：作業地點、集合時間、接駁與現場對口一看就懂。
・上下班打卡：在手機上打卡，工時與加班自動計算。
・工作行事曆：看接下來排到哪些工作。
・薪資：本月薪資試算與歷史薪資單，底薪、加班、勞健保自付額逐項列出。
・請假：在 App 內申請，合作社審核結果會透過 LINE 通知你。
・技能進度：查看自己的技能紀錄與評核。

【合法與保障】
・合作社為法定雇主，依規定辦理勞保、健保與職災保險。
・出勤與薪資紀錄由系統保存，查詢透明。

【使用方式】
第一次開啟時選擇身分（農場主或本國工人），再用合作社提供的帳號登入。農場主可以在 App 內註冊。
帳號、密碼問題請洽合作社專線。
```

（約 580 字元，遠低於 4,000 上限；之後可再補案例或常見問題。）
