LINE 官方帳號

農場主與工作人員分屬兩個官方帳號。這裡看兩個帳號的設定狀態，以及誰綁定了哪個 LINE 帳號。

帳號狀態

推播

訂單狀態變更、定金入帳、天候警戒會自動通知。工作人員只會收到自己出工名單的通知，並依各自的語言發送。

明日出工通知
每天傍晚自動發給隔天的出工名單。
只會發到「智農派工（農場主）」帳號。工作人員帳號不做全員廣播。
薪資入帳通知

合作社把薪資撥進工人的薪轉帳戶之後，在這裡貼上實發名單發送。每位工人只會收到自己的金額，並依各自的語言發送。金額請填實際撥出的數字，不要用系統試算值。
