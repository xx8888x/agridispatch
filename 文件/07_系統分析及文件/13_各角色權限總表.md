# 智農派工 各角色權限總表（2026-10-16）

> **用途**：一份看完所有角色能做什麼、不能做什麼，給合作社、律師、產品與開發對照。
> **依據**：後端 `AuthInterceptor`（`PUBLIC`／`ADMIN_ONLY`／`STAFF_ONLY` 三張清單）、`AuthContext`、各 Controller／Service 的 `requireAdmin()`／`requireStaff()` 檢查，以及 `03_認證與API安全規格.md` 第 5 節。
> **與其他文件的關係**：`11_合作社角色權限規格(草案).md` 是合作社角色的設計說明與待確認事項；本文件是**全部角色的實作現況總表**。兩者不一致時以程式與 03 為準，並回頭更新本文件。
> **法規疑點**：標【待確認】的項目交由律師或主管機關，本文件不下法律結論。

## 1. 角色一覽

| 角色 | 代碼 | 誰使用 | 登入入口 | 說明 |
|---|---|---|---|---|
| 訪客 | （無 token） | 未登入的任何人 | — | 只能用公開端點：登入、農場主自助註冊、試算、作物與行事曆、文宣、公開查驗、刪除帳號網頁申請、邀請連結登記 |
| 農場主 | `farmer` | 下單的農場、果園 | `farmer-login.html`（可自助註冊） | 只能看與操作**自己**的農場、訂單與付款 |
| 本國工人 | `worker_local` | 本國工人，`subRole` 區分：`labor` 一般勞務、`foreman` 領班、`machinery` 機耕／飛手 | `worker-local-login.html` | 只能看與操作**本人**資料；領班另可評核同工班組員 |
| 外籍移工 | `worker_foreign` | 外展移工 | `worker-foreign-login.html` | 權限同本國工人（本人範圍），無領班評核 |
| 合作社管理員 | `coop_admin` | 合作社人員（法定雇主） | `admin-login.html` → `coop.html` | 雇主責任範圍內的操作；不能動系統設定、帳號角色、代建訂單 |
| 科技後台管理員 | `admin_tech` | 科技公司（受託代管系統） | `admin-login.html` → `admin.html` | 全部權限 |
| LINE Bot | （內部金鑰） | LINE 農場主／工作者兩個官方帳號 | — | 只能呼叫 `/api/line/internal/**`，以 `X-Internal-Key` 驗證；未設定金鑰整組回 403 |

補充：
- 工人**不開放自助註冊**，必須由合作社查驗證件後建檔；工人只能在邀請連結留下意願登記，由合作社跟進。
- **demo 模式**的 demo token 視同 `admin_tech`，方便路演切換角色；但合作社的 demo token **不**視同管理員（`isAdmin()` 排除 `coop_admin`），示範時看得到限制。**正式模式一律拒絕 demo token。**
- 現在只有**單一合作社**，角色不帶「所屬合作社」欄位。

圖例：✏️ 可看可改　👁 只能看　🔒 僅限本人／自己的資料　✅ 可使用　⛔ 不可（403）　— 不適用

## 3. 合作社帳號不能做的事

合作社是法定雇主，雇主責任範圍內的操作都能做；以下**留給科技公司**，需要時請聯絡科技公司。（原本顯示在 `TechBackend/coop.html` 首頁，2026-10-16 起首頁不再顯示，內容移到本節。）

- 切換天候情境、LINE 與 App 推播、作物基準、產品文宣、人才庫、示範資料重灌
- 重設管理員帳號的密碼、審核刪除帳號申請
- 代農場主建立訂單、修改訂單、取消訂單、替訂單付定金、評價工班、直接改訂單狀態（合作社對訂單只能查看；尾款登錄與發票補登仍屬合作社）
- 工人證件的完整號碼（只顯示遮罩後的號碼）
- 新增或刪除管理員帳號、變更任何帳號的角色
- 看到後台帳號（帳號清單只列農場主與工人）

合作社的後台首頁只列雇主作業：農工名冊與派工調度、保險登錄、出勤與月結算、請假審核、推薦紀錄、派工媒合、共享班表、技能複核、帳號與密碼管理。

## 5. 通用規則

- **未帶或無效 token** → 401 `UNAUTHORIZED`；**權限不足** → 403 `FORBIDDEN`。
- Token 有效 12 小時；改密碼、登出所有裝置、被重設密碼、角色變更或帳號刪除後，舊 token 立即失效。
- 登入失敗鎖定：同帳號 15 分鐘內失敗 5 次或同 IP 失敗 30 次，之後 15 分鐘一律回 429（測試期開關 `login-lock-admin-only` 也涵蓋 `coop_admin`）。
- 「本人」判斷：農場主以 `order.farmerId == token.ref`；工人以 `workerId == token.ref`；後台人員（`admin_tech`、`coop_admin`）對 `/api/workers/{id}/**` 視同本人。
- 授權有三層：`AuthInterceptor` 的路徑清單（`ADMIN_ONLY`、`STAFF_ONLY`）、Controller／Service 內的檢查、資料列過濾（本人訂單、同工班）。**新增 API 時三層都要檢查**，並補 `CoopRoleTest`／`AuthHardeningTest` 的允許與拒絕案例。
